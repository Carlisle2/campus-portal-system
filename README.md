## 📖 项目简介

智慧校园信息门户系统是一款基于 Java Web 技术栈构建的综合性校园信息管理与服务平台。本项目采用 B/S 架构，旨在为现代教育机构提供一套兼顾“前台师生浏览”与“后台高效管理”的数字化校园解决方案。

系统采用前后台分离的设计理念，前台提供简洁高效的响应式信息浏览界面，后台配备功能完备的 CMS（内容管理系统）及数据可视化仪表盘。

## 🛠️ 技术栈

- **前端**：HTML5, CSS3, JavaScript (原生实现响应式布局与交互)
- **后端**：Java (JSP, Servlet, JavaBean), MVC 设计模式
- **数据库**：MySQL (使用 DAO 模式进行数据持久化)
- **服务器与开发工具**：Apache Tomcat, Eclipse IDE
- **第三方组件**：Chart.js (数据可视化), CKEditor 5 (富文本编辑器)

## ✨ 核心功能模块

### 1. 前台信息展示模块
- **模块化首页**：多区域卡片式布局（轮播图、重要通知、学工动态、学习资源、学院表彰等），支持异步动态加载。
- **新闻浏览系统**：分级内容展示，支持按分类筛选、关键词全文检索，以及分页展示。
- **用户系统**：基于 AJAX 的异步注册与登录，包含前端 JS 格式验证、密码强度校验及防暴力破解的验证码机制。

### 2. 后台内容管理模块 (CMS)
- **数据可视化仪表盘**：利用 Chart.js 实时统计用户总数、新闻发布量，绘制近30天发布趋势折线图与分类占比饼图，并展示热门新闻 TOP5。
- **新闻管理**：集成 CKEditor 富文本编辑器，支持图文混排；独创“七区域显示控制”，可一键设定新闻在前台的展示位置。
- **用户与角色管理**：基于 RBAC（基于角色的访问控制）思想，支持动态分配角色。内置安全删除机制，若角色被占用则拒绝删除，保障数据完整性。

## 🔒 安全与工程实践
- **防 SQL 注入**：全站数据库操作采用 `PreparedStatement` 预编译处理。
- **权限控制**：后台所有页面强制校验 Session 登录状态，拦截非法直接访问。
- **防误操作**：所有删除操作均触发二次确认弹窗。

## 🚀 快速开始

1. 使用 **Eclipse IDE** 导入项目（File -> Import -> Existing Projects into Workspace）。
2. 在 MySQL 中创建数据库 `website`，并导入 `website.sql` 初始化表结构与数据。
3. 修改 `src/main/java/pub/ConnDB.java` 中的数据库连接账号与密码。
4. 配置 Tomcat 服务器（Server -> Add and Remove），部署项目并启动。
5. 访问 `http://localhost:8080/项目名/` 即可查看前台。
